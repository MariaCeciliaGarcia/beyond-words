# Beyond Words

一个围绕可迁移英语语块的网页练习工具。无需登录、无需付费 API，学习进度保存在浏览器本地。

## 当前功能

- Spoken English（日常交流、职业交流）和考试顺利（雅思、四级、六级、托福）表达库。
- 261 个表达单元；输入造句、情境判断、无输入回忆等练法。三种不同练法首先在 `in the evening`、`be done with…`、`Fair enough.` 落地。
- 默认隐藏英文与提示，按需查看用法规则；个人例句和个人场景可保存、修改、复习。
- 首页直接继续上次学习或复习，保留当前题目、输入、提示和队列。
- 复制带有中文意思及目标语块的 AI 核对指令，由用户自行粘贴给常用 AI；网页不会自动向外发送学习内容。
- 导出/导入 JSON 进度备份、导入预览、合并或替换、撤销导入、本地恢复副本。
- 浅色玻璃视觉系统，统一文字层级、控件状态及响应式布局。

## 本地运行

在项目目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://localhost:8765/`。macOS 也可以双击 `启动预览.command`。

## 检查

需要 Node.js，无需安装 npm 依赖：

```sh
node validate.cjs
node validate-support.cjs
```

第一项检查题库、分类、学习复习流程及旧数据兼容；第二项检查提示规则、继续入口、备份恢复、存储异常和多标签页边界。

## 学习数据

普通刷新保留已成功保存的进度。清除网站数据、使用无痕浏览，或更换浏览器、地址和端口时，不能依赖原来的本地存储。

请在网页右上角「进度备份」导出文件。在另一浏览器或设备打开网页，选择「导入备份」，确认后从首页继续。备份不是云端同步；本地恢复副本同样不能抵抗手动清除网站数据。

浏览器中的个人进度与例句不属于项目源码，不应提交到仓库。历史压缩备份留在本地，仓库版本通过 Git 提交与标签保存。
