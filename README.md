# Beyond Words

一个围绕可迁移英语语块的网页练习工具。无需登录、无需付费 API，学习进度保存在浏览器本地。

## 当前功能

- Spoken English（日常交流、职业交流、Cecilia 每日语料）和考试顺利（雅思、四级、六级、托福）表达库。
- 323 个表达单元；输入造句、情境判断、无输入回忆等练法。三种不同练法首先在 `in the evening`、`be done with…`、`Fair enough.` 落地。
- 初试结果居中反馈；初试答对的重复题计入本轮，继续时换新题，不增加确认步骤。
- 默认隐藏英文与提示，按需查看用法规则；个人例句和个人场景可保存、修改、复习。
- 首页直接继续上次学习或复习，保留当前题目、输入、提示和队列。
- Spoken English 内的 Cecilia 按日期收录每日材料；2026-10-28 含97条原材料、70个练习表达（62新增、8复用），新增内容不混入公共日常或职业库。
- 当天处理状态与全局掌握分开；日期内学习、复习和下一表达保持来源。
- Enter执行核对、会了、下一步等安全主要动作；个人多行输入保留换行，⌘/Ctrl+Enter保存。未作答选择题、输入法确认字及危险弹窗不自动推进。
- 词语提示直接提供词汇/搭配，句式提示提供结构和语法规则；配套帮助与目标曝光分别记录。
- 复制带有中文意思及目标语块的 AI 核对指令，由用户自行粘贴给常用 AI；网页不会自动向外发送学习内容。
- 导出/导入 JSON 进度备份、导入预览、合并或替换、撤销导入、本地恢复副本。
- 自建例句累计保留；中文输入建议仅提供最近一项，与保存数量独立。
- 宽屏学习/核对/讲解与情境题采用等宽等高双栏；学习、复习、自建内容和相关弹窗统一较大文字与控件尺度，窄屏自然恢复单栏。
- 浅色玻璃视觉系统，统一文字层级、控件状态及响应式布局。

## 本地运行

在项目目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://localhost:8765/`。macOS 也可以双击 `启动预览.command`。

## 检查

需要 Node.js，无需安装 npm 依赖：

```sh
node validate.cjs
node validate-support.cjs
node validate-keyboard.cjs
node validate-daily.cjs
node validate-notes.cjs
node validate-ui.cjs
```

第一项检查题库、分类、学习复习流程及旧数据兼容；第二项检查提示规则、继续入口、备份恢复、存储异常和多标签页边界。

## 学习数据

普通刷新保留已成功保存的进度。清除网站数据、使用无痕浏览，或更换浏览器、地址和端口时，不能依赖原来的本地存储。

请在网页右上角「进度备份」导出文件。在另一浏览器或设备打开网页，选择「导入备份」，确认后从首页继续。备份不是云端同步；本地恢复副本同样不能抵抗手动清除网站数据。

浏览器中的个人进度与例句不属于项目源码，不应提交到仓库。历史压缩备份留在本地，仓库版本通过 Git 提交与标签保存。

## AI解释范围（1.14.3）

AI核对指令默认学习者已熟悉目标表达，不重复讲解其意思、基本用法或对应知识点；只解释句中其他有学习价值的词语、搭配和语法，无其他难点可省略讲解。目标表达用错或不适用时，仅说明具体问题与必要修改理由。造句与独立回应均适用。

## 结果页的对称层级与操作（1.14.4）

- 每日库继续按钮统一“继续学习”；返回原日期列表用“返回本日语料”，全部日期范围用“返回日期目录”。继续与返回横排，和下方操作共用等宽两列及高度；窄屏仍保持两枚按钮横排。普通学习、复习及掌握结果同类操作一起对齐。
- 初试及学习／复习核对中，“你的表达：”与“参考表达：”采用对称标签及同字号、字重、行高和间距，宽屏并排，窄屏同结构上下排列。初试结果的返回修改与笔记入口纵向左对齐，保留笔记自动保存及原输入。
